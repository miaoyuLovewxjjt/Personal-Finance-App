# 像素记账（PixelBook · Personal Finance App）

安卓端像素风个人记账应用。星露谷式低分辨率像素马赛克视觉：米白棋盘纹理背景、深棕像素描边、阶梯硬阴影、Zpix 像素字体、无渐变渲染；数据全部存储在本地，无需联网。

## ✨ 功能一览

### 账本管理
- 新建 / 编辑 / 删除账本；账本名称 ≤ 30 字，长名自动换行
- 每本账本可自定义：名称、**字体**（像素 Zpix / 可爱风·站酷快乐体 / 楷体·霞鹜文楷 / 宋体·站酷小薇）、**封面颜色**
- 主页右上角设置：数据存储目录切换（SAF，支持迁移到外部目录并自动同步）

### 记账明细
- 左侧 年 → 月 → 日 多级导航，顶部折叠按钮可收缩导航栏
- 每日收入 / 支出分区块展示；记录可编辑、删除
- 类别下拉内置 **「自定义」** 输入，新类别自动记入全局类别表

### 类别维护（设置内）
- 收入 / 花销分别维护：新增、编辑、删除；「其他」固定不可动
- 删除被引用类别 → 全部记录自动回退为「其他」
- 编辑被引用类别 → 全部记录自动同步为新名称

### 总结与图表
- **今日总结**（明细列表底部）：总收入 / 总支出 / 今日结余、最大收入 / 最大花销
- **月度总结**：总支出 / 总收入 / 总结余、支出最多日 / 收入最多日、本月最大收入 / 花销（带日期）、本月收入 / 花销占比环形图
- **年度总结**：同上（年度维度）+ 支出最多月 / 收入最多月（可跳转）、**按月收入 / 花销双柱图**
- 图表交互：点击扇形 / 柱形显示「分类 + 金额 + 占比」、点击图例显隐分类、环形图中心显示总金额

### 导出
- 记账明细页右上角打印机图标 → 导出本账本为 **PDF**（像素风排版，章节：账本信息 → 存款明细 → 收支流水 → 总结）

### 存款明细
- 金钱类 / 非金钱类分组，编辑、删除，自动统计总存款

## 🛠 技术要点
- 原生 **Kotlin + Jetpack Compose**（单 Activity + 状态栈导航），minSdk 24 / targetSdk 35
- 数据层：SharedPreferences / SAF 目录双后端（`LedgerIO` 抽象，目录切换自动迁移），金额一律以「分」存储避免浮点误差
- 自绘像素 UI：图标库为 16×16 字符画放大渲染；图表（环形图 / 柱状图）为 Canvas 自绘，支持点击命中与图例交互
- PDF 导出：`android.graphics.pdf.PdfDocument` 手绘像素风（整页软件位图渲染，规避 hwui 崩溃）
- 内置开源字体：Zpix（像素）、站酷快乐体（ZCOOL KuaiLe）、霞鹜文楷（LXGW WenKai Lite）、站酷小薇（ZCOOL XiaoWei），均遵循 SIL OFL 许可

## 🚀 构建

```bash
./gradlew assembleDebug     # 调试包
./gradlew assembleRelease   # 正式签名包（使用 keystore/ 下签名配置）
```

产物位于 `app/build/outputs/apk/`；可分发安装包同步在 `dist/` 目录（不入库）。

