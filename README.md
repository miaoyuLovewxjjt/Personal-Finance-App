# 像素记账（PixelBook · Personal Finance App）

安卓端像素风个人记账应用。星露谷式低分辨率像素马赛克视觉：米白棋盘纹理背景、深棕像素描边、阶梯硬阴影、Zpix 像素字体、无渐变渲染；图标为手绘 + 马赛克化处理；数据全部存储在本地，无需联网。

## ✨ 功能一览

### 账户体系
- **账户**（我的记账）：一个账户下可建多个账本（每账户最多 60 本）；账户可新建 / 编辑 / 删除 / 切换，同名不允许
- 账户名即存储文件夹名，修改账户名/账本名会自动同步重命名文件夹与文件
- 旧版数据首次启动自动迁入「默认账户」（幂等迁移，旧 SharedPreferences / 三文件结构自动整理）

### 我的存款（账户公用一本）
- 存款为**账户级公用**：不分账本、一本到底，各账本旧存款已自动汇入并标注来源
- 金钱类 / 非金钱类分组；新增 / 编辑 / 删除；自动统计总存款
- 顶部可「显示 / 隐藏」金额（两段式像素开关）

### 我的钱包（资产账户信息）
- 维护银行卡、支付宝、微信等**资产来源**：来源下拉（支付宝 / 银行卡 / 微信 / 自定义）、账号（≤20 字）、角色（≤10 字，账户内不可重复）
- 按来源分组卡片展示，**最新余额**由每笔收支自动累计（只读不可手改），支持隐藏金额/卡号
- **每日流水**：左侧 年 → 月 → 日 导航，按资产账户分组展示当日全部流水（收入 + / 支出 -），可折叠分组、可隐藏金额
- 与记账联动：记账时可选择「支付 / 到账资产账户」，明细行显示资产名

### 记账簿（每账户多账本）
- 新建 / 编辑 / 删除账本；账本名 ≤ 30 字、封面颜色、账本字体（像素 Zpix / 可爱风 / 楷体 / 宋体）
- 明细页：左侧 年 → 月 → 日 多级导航（可折叠收缩）+ 每日流水区块
- 收入 / 支出分别录入：金额（≤9 位整数 + 2 位小数）、名称（≤25 字）、备注（≤30 字）、自定义类别（≤10 字，**记账时手动新增**，按账户存储、账户内通用）
- **今日预算**：每日标题下方设置当天花销预算；今日总结含「今日花销预算 / 花销超出（未超支）」
- 日历按钮：左侧导航顶部，弹出带**每日结余**的日历（按天显示 +正/-负）

### 总结与图表
- **今日总结**：总收入 / 总支出 / 今日结余、今日花销预算 / 花销超出、最大收入 / 最大花销
- **月度总结**：总支出 / 总收入 / 总结余、支出/收入最多日、本月最大收入 / 花销、收入 / 花销占比环形图；「一键同步」把当月结余归档到我的存款（标注账本来源）
- **年度总结**：同上（年度维度）+ 支出/收入最多月（可跳转）、按月收入 / 花销双柱图
- 图表交互：点击扇形 / 柱形显示「分类 + 金额 + 占比」、点击图例显隐分类

### 导出
- 记账明细页右上角 → 导出 **PDF**（像素风排版，章节：账本信息 → 我的存款 → 收支流水 → 总结）

## 📂 数据存储（设置内）
- 根目录 `pixelbook_accounts.json` = 账户索引；每个账户一个**以账户名命名的文件夹**，内含：
  - `ledgers.json`（账本索引）、`cats.json`（该账户类别）、`{账户名}_资产信息.json`（资产账户）、`{账户名}_存款明细.json`（账户公用存款）
  - 每账本一个 `{账本名}_{创建时间戳}.json` 数据包（收支 + 天气 + 每日预算）
- 存储位置：应用内部 或 设置中选择的 SAF 目录；切换目录 = 整棵账户树迁移；历史目录可查可复制
- debug 版提供「存储自检」；release 版干净无诊断入口

## 🛠 技术要点
- 原生 **Kotlin + Jetpack Compose**（单 Activity + 状态栈导航），minSdk 24 / targetSdk 35
- 数据层：内部文件 / SAF 目录双后端，按账户文件夹组织；金额一律以「分」(Long) 存储避免浮点误差；版本升级自动迁移（账户化、存款公用化均幂等）
- UI：像素组件库 + 16×16 字符画图标（折叠箭头/铅笔等）+ **手绘马赛克图标资源**（垃圾桶/返回/设置/日历/账本/证件卡/钱袋等，透明底硬边渲染）；图表 Canvas 自绘支持点击
- PDF 导出：`android.graphics.pdf.PdfDocument` 软件位图渲染
- 内置开源字体：Zpix / 站酷快乐体 / 霞鹜文楷 / 站酷小薇（SIL OFL）

## 🚀 构建

```bash
./gradlew assembleDebug     # 调试包（含「存储自检」诊断入口）
./gradlew assembleRelease   # 正式签名包（keystore/pixelbook.keystore）
```

产物位于 `app/build/outputs/apk/`（debug / release），可分发安装包另存于项目外 `APK/` 目录（不入库）。

## 📁 项目结构

```
app/src/main/java/com/miaoyu03/pixelbook/
├── MainActivity.kt        # 入口与页面路由（单 Activity 状态栈）
├── data/                  # 数据模型与 Store（账户 / 账本 / 类别 / 资产 / 存款 存储层与迁移）
├── export/                # 像素风 PDF 导出
└── ui/
    ├── Icons.kt           # 16x16 字符画像素图标库
    ├── Theme.kt           # 调色板 / 字体 / 字号规范
    ├── Widgets.kt         # 像素组件库（面板/按钮/表单/开关/图表）
    └── screens/           # 首页(账户) / 记账簿 / 我的存款 / 我的钱包 / 总结页
app/src/main/res/drawable-nodpi/   # 手绘马赛克图标资源（ic_px_*）
```
